# 多机台智能排产算法 · 可视化方案设计

> 阶段一.6：可视化设计（待人工审核）。针对大规模调度（L4/L5）甘特图失效问题，提出分层可视化方案。

## 0. 问题诊断：甘特图为何在大规模失效

| 问题 | 说明 |
|------|------|
| 信息过载 | L5 500 订单 → 500 横条，30 机台纵向堆叠 → 无法辨认单个订单 |
| 模式淹没 | 瓶颈、负载不均、延误聚集等宏观模式被密集条形淹没 |
| 切换看不清 | setup/cleanup 是小间隙，在密集甘特图中不可见，但切换开销恰是优化关键 |
| 无聚合指标 | 甘特图是"明细视图"，缺负载率、准点率、均衡度等聚合指标 |

**结论**：甘特图本质是「单机/小规模明细视图」。大规模需「聚合视图为主 + 明细下钻为辅」的分层可视化。

---

## 1. 分层可视化策略（核心）

```
[全局层] KPI 仪表盘 + 负载图 + 延误散点   ← 主视图（大规模必看）
    │ 下钻
[瓶颈层] Top-K 瓶颈机器放大甘特图          ← 甘特图在此仍适用（单机/少数机台）
    │ 下钻
[明细层] 单个订单/机台的完整时间线          ← 交互悬停/点击查看
```

---

## 2. 推荐图表清单（按用途）

### A. 机器负载堆叠图（替代甘特图的主视图）★ 核心

```text
横轴 = 机台（m1~m30）
纵轴 = 时间
堆叠段 = 有效加工时间 / 切换+清理时间 / 空闲时间（三色堆叠）
```
- **价值**：一眼看出①瓶颈机器（总负载最高）②负载均衡度③切换开销占比（切换段越高越浪费）
- **衍生**：负载标准差 / 变异系数 CV 作为均衡度量化指标

### B. 时间-机器热力图（Timeline Heatmap）★ 核心

```text
横轴 = 时间轴；纵轴 = 机台；颜色 = 状态（加工/切换/空闲）或配方类型
```
- **价值**：比甘特图密度低、信息聚合；配方色块直接暴露「切换频繁区」与「同配方聚集区」
- **适用**：L4/L5 全时间线模式洞察；L5 500 单压缩成 30 行色带可读

### C. 完工 vs 交期散点图 ★ 交期表现

```text
横轴 = 交期 d_j；纵轴 = 完工 C_j；对角线 = 准点线
线上 = 延误；线下 = 提前；点大小/颜色 = 加工时长或延误量
```
- **价值**：500 个点也能看清整体准点率、延误聚集区间（交期早的订单延误严重？）

### D. 延误分布图

```text
直方图 / 箱线图：延误 T_j 的分布；累计延误曲线（订单按交期排序）
```
- **价值**：延误的集中度与尾部风险（少数订单占大部分延误？）

### E. 切换开销统计

```text
柱状图：每机器切换次数；饼图/堆叠：切换时间占总时间比
```
- **价值**：切换时间远大于加工时间的场景（boundary 5~20 vs 1~60），切换优化是核心杠杆

### F. 求解过程收敛曲线（元启发 L4/L5）

```text
横轴 = 求解时间；纵轴 = 目标值（或 gap）
曲线 = ALNS/禁忌迭代改进轨迹；可选叠加 CP-SAT 下界
```
- **价值**：展示求解质量演进、是否收敛、还有多少提升空间

### G. KPI 仪表盘

```text
卡片指标：Cmax / ΣT / ΣC / 平均延误 / 准点率 / 瓶颈机器 / 负载 CV
```

## 3. 各层可视化映射

| 层级 | 规模 | 主视图 | 辅助视图 |
|------|------|--------|----------|
| L1 toy | 5 单 | 甘特图（手工验证） | KPI 卡片 |
| L2 boundary | 12 单 | 甘特图 | 切换统计 + KPI |
| L3 medium | 50 单 | 负载图 + 延误散点 | 简化甘特图 + KPI |
| L4 large | 200 单 | 负载图 + 热力图 + 延误散点 | 瓶颈甘特图（Top-K 下钻） |
| L5 massive | 500 单 | 负载图 + 热力图 + 延误散点 + KPI | 收敛曲线 + 瓶颈下钻 |

---

## 4. 技术选型

| 工具 | 用途 | 说明 |
|------|------|------|
| matplotlib | 静态图（负载图/延误散点/收敛曲线/KPI） | 嵌入 HTML 过程报告（沿用 build_report.py） |
| plotly | 交互图（热力图/下钻/悬停明细） | 独立 HTML，可缩放/筛选，适合 L4/L5 探索 |

**建议**：报告内嵌 matplotlib 静态图（保证离线可读）；L4/L5 额外生成 plotly 交互 HTML（热力图 + 瓶颈下钻）。

---

## 5. 甘特图的保留场景

甘特图**不废弃**，仅降级为「下钻明细视图」：
1. L1/L2 手工验证（必须，逐单对照）
2. 瓶颈机器的单机甘特图（下钻后只看 1 台机器，甘特图重新适用）
3. 单个订单的时间线明细（交互悬停）
