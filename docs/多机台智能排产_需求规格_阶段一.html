一、问题概述与业务背景

车间有多台机台，每台只能加工 allowed_recipes 允许的配方。每个订单指定配方、数量、交期（priority 字段忽略，D1），订单不可拆分（整单 = 一个不可中断加工块）。机台切换配方需切换时间（对角=同配方清理，非对角=跨配方切换，均叠加机台 cleanup_time），部分配方对不可切换（null，可绕行）。目标从 makespan / tardiness / 总完工时间 中选 1~3 个，多目标用加权和组合，λ 由用户定义（默认 (0,1,0)，保留多目标能力）。构建原则：性能优先，数据决定模型。

⚠ 两个关键业务判断: ① 订单不可拆分 → 建模粒度 = 整单（加工时间 = 数量 × 配方单件加工时间）；② load_factor 全部 >1（产能过载）→ 交期软约束，makespan 必超计划周期。

数据体检关键发现（决定模型口径）

发现 1（不可行切换）: switch_matrix 用 null 表达「配方 u→v 不可直接切换」（boundary 4×4 含 8 个 null = 50%）。null ≠ 完全互斥，可经中间配方绕行（C4 默认）。

发现 2（产能过载，决定性）: load_factor，toy=0.56（富余），boundary=1.89、medium=1.69、large=1.85、massive=1.75（全部过载）。→ 交期软约束，makespan 必超 plan_horizon，tardiness 成为核心目标。

发现 3（priority 忽略）: D1 确认忽略 priority 字段——不进目标、不作为权重，仅在输出结果中作展示参考。

四、范式识别与复杂度判定

范式: 并行机调度 + 序列相关设置时间 + 机器-配方兼容性。每台机器的订单排序本身是带序列相关 setup 的非对称 TSP 子问题，叠加机器分配与兼容性。记为 P_m | M_j, s_uv | 三目标。

复杂度: 无 setup 时 P_m||ΣC_j 已 NP-难；序列相关 setup 使单机排序成为非对称 TSP。结论：L1~L3 用 CP-SAT 精确/时间限制；L4 时间限制 + 元启发兜底；L5 元启发为主（数据决定模型）。

五、数学模型（订单粒度，三目标加权和，无权重）

集合 Sets

$$ \mathcal{J} = \{1,\ldots,n\} \text{ 订单}, \quad \mathcal{M} = \{1,\ldots,m\} \text{ 机台}, \quad \mathcal{R} \text{ 配方}, \quad \mathcal{R}_m \subseteq \mathcal{R} \text{ 机台 } m \text{ 可加工配方} $$

参数 Parameters

$$ p_j = q_j \cdot t_{\rho_j}: \text{订单 } j \text{ 加工时间（整数，不可拆分）}, \quad \rho_j: \text{订单 } j \text{ 配方} $$
$$ d_j: \text{交期} \qquad \text{（priority 字段忽略，D1）} $$
$$ c_m: \text{机台清理时间}, \qquad s_{uv}: \text{配方 } u \to v \text{ 切换时间（对角=清理，非对角=切换，null=禁止，可绕行）} $$

决策变量 Decision Variables

$$ x_{jm} \in \{0,1\}: \text{订单 } j \text{ 分配机台 } m $$
$$ S_j \ge 0: \text{开工}, \qquad C_j = S_j + p_j: \text{完工（定义式，不可中断）}, \qquad T_j \ge 0: \text{延误} $$

目标函数（三目标加权和，λ 由用户定义）

$$ \min \; \lambda_1 C_{\max} + \lambda_2 \sum_{j} T_j + \lambda_3 \sum_{j} C_j, \qquad C_{\max} = \max_j C_j \tag{(1)} $$

三基础目标（均无权重）: ① makespan C_max；② tardiness Σ T_j（总延误，D1 无权重）；③ 总完工时间 Σ C_j（C1 无权重）。λ = (λ1, λ2, λ3) 由用户定义（接口留出），至少一个非零；选 1 项 = 单目标，选 2~3 项 = 多目标。默认 λ=(0,1,0)（tardiness 单目标，D2），保留多目标能力。

约束条件 Constraints

$$ \sum_{m} x_{jm} = 1, \quad \forall j \qquad \text{每订单恰一机台} \tag{(2)} $$
$$ x_{jm} = 0 \; \forall j,m: \rho_j \notin \mathcal{R}_m \qquad \text{机器-配方兼容性} \tag{(3)} $$
$$ \text{每机台 } m \text{ 上订单区间 } [S_j, C_j) \text{ 两两不重叠（NoOverlap）} \tag{(4)} $$
$$ \text{同机台相邻 } j \to k: S_k \ge C_j + c_m + s_{\rho_j \rho_k} \; (s \ne null) \qquad \text{切换+清理（叠加）} \tag{(5)} $$
$$ T_j \ge C_j - d_j, \quad T_j \ge 0 \qquad \text{延误定义（软约束）} \tag{(6)} $$
$$ C_{\max} \ge C_j \; \forall j, \qquad C_j = S_j + p_j, \; S_j \ge 0 \qquad \text{makespan 定义 + 不可中断 + 变量域} \tag{(7)} $$
⚠ 切换时间 (5) 的 null 处理：CP-SAT 中 null 配方对不建立 transition 边（绕行）；元启发中 null 边视为不可行移动。三个目标均无权重（D1 忽略 priority，C1 总完工时间无权重）。

六、求解方案选型（数据决定模型，自适应框架）

层级求解器策略验收（性能优先）
L1 toy (5 单)CP-SAT精确求解，证明最优正确解 + 手工验证，秒级
L2 boundary (12 单)CP-SAT精确 + null 鲁棒处理不崩溃，高 null 比例正确
L3 medium (50 单)CP-SAT (time limit)300s 时间限制 + best bound5 分钟内出可行解
L4 large (200 单)CP-SAT 时间限制 + 元启发兜底构造启发式初解 + LNS/ALNS15 分钟内出解
L5 massive (500 单)元启发（构造 + ALNS/禁忌/遗传）秒级初解 + 迭代改进可用解（有界 gap 或质量指标）

求解器: ① OR-Tools CP-SAT（精确层，L1~L3，L4 时间限制）；② SCIP（备选精确层）；③ 启发式 + 元启发（L4/L5 主力：EDD/LPT 列表调度初解 + 自适应大邻域搜索 ALNS + 禁忌搜索）。数据决定模型: 读取 metadata 规模自动路由求解层。

性能优先原则: 时间达标 > 最优性证明。L4/L5 达标即接受当前最优解，如实标注 gap/质量，禁止冒充最优。

八、可行性评估与建议（V4 定稿）

层级可行性主要风险应对
L1 toy (5 单)✓ 高无CP-SAT 秒级最优，手工对照
L2 boundary (12 单)✓ 高50% null 可行性判断null 建模 + 可行性预检 + IIS 诊断
L3 medium (50 单)✓ 高序列相关 setup 使最优性难证CP-SAT 300s 时间限制，达标即收
L4 large (200 单)✓ 中高CP-SAT 可能 15min 内无高质量解元启发兜底 + warm start
L5 massive (500 单)⚠ 中（可用解）500 单 × 序列相关切换精确不可能构造启发式 + ALNS，达标=可用解

整体结论: 需求可行。订单不可拆分后决策规模 = 500 订单，L1~L3 精确求解无悬念，L4 时间限制 + 兜底，L5 元启发求可用解。三个关键风险与建议：

风险 1（序列相关切换 = 非对称 TSP）: 每机订单排序是 TSP 子问题，切换时间远大于加工时间时排序优化收益高。建议 CP-SAT 用 circuit/transition 表达，元启发用「配方分块」邻域减少切换。

风险 2（过载负载）: L2~L5 产能不足，makespan 必超计划周期，tardiness 目标质量依赖启发式设计。默认 λ=(0,1,0) 以 ΣT 为主目标，与过载场景适配。

风险 3（多目标 λ 标量化）: makespan 与 tardiness 在过载下冲突。λ 接口留出（C3），默认 (0,1,0)，用户可切换任意组合。
